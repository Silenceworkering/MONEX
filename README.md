# FINORA 1.2
Русскоязычный мобильный учёт личных финансов: доходы, расходы, помесячная история, аналитика категорий, бюджет, резервные копии, OCR чеков.

## iPhone
Публикация через GitHub Pages: Settings → Pages → Source: GitHub Actions. После деплоя открыть сайт в Safari → Поделиться → На экран «Домой».

## Android
Actions → Android APK → Run workflow; после сборки скачать артефакт `FINORA-Android-debug-APK`.

## Ограничения
OCR требует загрузки Tesseract.js из CDN и может ошибаться; подтверждайте сумму. Данные в localStorage, не синхронизируются между устройствами. Это debug APK, не релизная подписанная сборка. PIN и банковские интеграции пока отсутствуют.
